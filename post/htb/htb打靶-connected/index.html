权限提升

必备知识 

一、Incron —— 基于文件系统事件的"定时任务"替代品
Incron（inotify cron）本质上是一个事件驱动的自动化守护进程，不是按时间来触发任务，而是当某个文件/目录发生变化时立刻触发脚本。

组成:incrond（后台守护进程）+ incrontab（管理表，用法类似 crontab）

监听事件:文件创建/删除/修改/移动/属性变化等（IN_CREATE、IN_DELETE、IN_MODIFY…）

典型用途:配置文件变更后自动 reload 服务、上传目录有新文件自动处理、关键文件防篡改监控、自动备份/版本化等

简单例子：监控 /etc/nginx/conf.d/，一旦有 .conf文件新增或修改，就自动执行 nginx -t && systemctl reload nginx。

⚠️ 安全角度提示：Incron 本身不是恶意软件，它是合法的系统工具（Debian/Ubuntu 仓库里就有）。但因为它能静默地在文件变化时执行任意命令，如果服务器上出现了来历不明的 incron 规则（incrontab -l或 /etc/incron*），确实需要审查——它可能被人用作持久化/应急响应对抗的手段。

二、DAHDI —— 电话硬件驱动框架（Asterisk 电话系统用）

DAHDI（Digium/Asterisk Hardware Device Interface）是一套 Linux 内核级驱动 + 用户态工具集，用于在服务器上驱动传统电话接口硬件卡（PCI/PCIe 板卡），让开源电话系统 Asterisk​ 能对接实体电话线路。
管什么:模拟电话口（FXO/FXS）、数字线路（T1/E1/PRI）、BRI ISDN 等电信接口卡
对外接口:/dev/dahdi/*字符设备、SysFS、/proc 等
你什么时候需要它:你的服务器上插了 Sangoma/Digium 等电话板卡，跑 VoIP-PSTN 网关或呼叫中心系统.

攻击链路梳理 

首先，要了解系统的特殊性。
	该系统为freepbx，该组件为“电话系统”，因此枚举时可关注电话系统涉及到的特殊的服务。

#寻找可利用的服务或文件。
	寻找可写的文件
	find /etc -writable 2>/dev/null | grep -v "/etc/wanpipe\|/etc/asterisk\|/etc/schmooze" | head -20
	
	发现/etc/dahdi/init.conf 文件，dahdi与电话相关组件。
	
#进一步发现Incron服务
	cat /etc/incron.d/legacy  #该目录/etc/incron.d下的文件为系统表，事件触发时会用root权限执行。
	
	发现此配置：
		/var/spool/asterisk/sysadmin/dahdi_restart IN_CLOSE_WRITE /usr/sbin/sysadmin_dahdi_restart
	解释：
		/var/spool/asterisk/sysadmin/dahdi_restart   ← 监控什么 ，监控的目标文件
		IN_CLOSE_WRITE                                 ← 什么事件，有进程以可写模式打开了这个文件，写完之后关闭了它（即一次 write→close 完成）
		/usr/sbin/sysadmin_dahdi_restart               ← 触发什么命令 ，事件发生后，立刻以root权限执行这个脚本
	
	--------------------
	到此，利用思路为：
		1.将恶意脚本写入/usr/sbin/sysadmin_dahdi_restart中
		2.向/var/spool/asterisk/sysadmin/dahdi_restart文件 作为触发条件。
		3.等待执行结果。
	--------------------
	# 此文件可修改：/var/spool/asterisk/sysadmin/dahdi_restart
	 ls -al /var/spool/asterisk/sysadmin/dahdi_restart                       
		-rw-rw-r--. 1 asterisk asterisk 5 Jun 19 14:35 /var/spool/asterisk/sysadmin/dahdi_restart
	
	# 该文件/usr/sbin/sysadmin_dahdi_restart  ，为root权限，无法修改。
	ls -al /usr/sbin/sysadmin_dahdi_restart
-rwxr-xr-x. 1 root root 157 Apr 15  2021 /usr/sbin/sysadmin_dahdi_restart
	
	# 查看文件内容，发现包含了此文件：/etc/init.d/dahdi
	
	cat /usr/sbin/sysadmin_dahdi_restart
        #!/bin/sh
        /etc/init.d/asterisk stop
        sleep 5
        /etc/init.d/dahdi restart
        sleep 5
        export PATH=$PATH:/usr/local/sbin/:/usr/local/bin/
        `which amportal` start
        
	# 该文件也是root权限
        ls -al /etc/init.d/dahdi
        -rwxr-xr-x. 1 root root 8496 Jun  5  2023 /etc/init.d/dahdi


	# 查看 /etc/init.d/dahdi 文件，存在/etc/dahdi/init.conf内容	
		.......................
        DAHDI_MODULES_FILE="/etc/dahdi/modules"
        [ -r /etc/dahdi/init.conf ] && . /etc/dahdi/init.conf 
        .........................
  ---------------------------------------
  至此,文件关系：
  	/usr/sbin/sysadmin_dahdi_restart  
  	---- /etc/init.d/dahdi 
   	---------/etc/dahdi/init.conf  <---将恶意脚本写入
